# AIVV roadmap

AIVV evolves through evidence-gated changes. The roadmap describes possible future work, not delivery commitments.

## Available today

- Advisory code review with reviewer and lens selection.
- A guarded investigate, fix, and verify workflow.
- Project calibration and read-only review output.
- Native plugin packages for Claude Code and Codex with shared workflows and host adapters; Codex custom-agent dispatch still needs separate profile installation and end-to-end validation.

## Under consideration

- A performance-focused review lens, if repeated evaluations show a gap in current coverage.
- Runtime visual review, after its evidence and safety requirements are met.
- Additional workflow integrations, based on maintainer capacity and user demand.

Issues and pull requests are considered on a best-effort basis. See [CONTRIBUTING.md](../CONTRIBUTING.md).
