# Security policy

Please report suspected vulnerabilities privately. Use GitHub's **Report a vulnerability** feature on this repository when it is enabled. Do not include exploit details, secrets, or sensitive data in a public issue or pull request.

If the private reporting feature is unavailable, open a brief public issue asking for a private reporting channel and omit technical details. The maintainer will review security reports on a best-effort basis; there is no formal response-time SLA. Security reports are prioritized over ordinary issues.

This policy applies to the latest public release. AIVV is provided under the MIT License and is an advisory review tool; do not send confidential project data in public reports.
